# 로컬 이미지 생성

몇년전인가, 한창 Stable Diffusion이 유행일 때 로컬 이미지 생성을 좀 해봤었다. 그 뒤로는 대화 모델에 더 흥미를 느껴서 더 해보진 않았고 지금은 그냥 ChatGPT의 이미지 생성 정도로 만족하며 쓰고 있음. 다만 전혀 문제될 게 없는데도 자꾸 스팸/사기/부적절이니 하면서 막는 게 좀 그랬다. 그러다 우연히 Anima라는 이미지 생성 모델을 알게 되었고 좀 간편하게 쓰려고 대화형 이미지 생성툴을 만들어봤다.

{/* truncate */}

기본적으론 Anima 같은 로컬 모델을 쓰려면 ComfyUI라는 툴이나 이걸 기반으로하는 다른 툴을 써야한다. Stability Matrix라는 툴을 쓰면 꽤 간편하게 시작해볼 수 있다.

문제는 툴이 너무 고급지다는 것이다. 그동안 ChatGPT의 대화형 "해줘"에 익숙해진 나에겐 99%가 불필요한 기능들이라 너무 난잡했다. 그래서 하나 만들었다.

![demo ko](https://cdn.neuwappbox.com/post/2026/10/05blog/assets/2026-10-05-moru/demo-ko.webp)

물론 찾아보면 비슷한 툴도 있을거고 이거보다 훨 좋겠지만 난 딱 이정도 기능이면 충분한 거 같다.

아키텍쳐는 뭐 별 거 없다. 파이썬이 백엔드이고 ComfyUI를 이미지 생성에 쓰며, 웹뷰로 React 프론트를 보여주는 구조다. 빌드한 결과물을 받는 사용자 입장에선 그냥 exe 실행만 하면 끝이다.

프롬프트의 경우엔 Qwen 같은 로컬 LLM을 통해서 이미지 생성용 프롬프트를 만들게 하는 구조다. 4B 정도 크기의 모델에 4k 컨텍스트가 한계라서 지침을 다듬는 게 좀 힘들었다. 대화형이기 때문에 이전 몇개의 요청과 직전 이미지 프롬프트를 같이 본다. 매번 전체를 설명할 필요가 없음.

한계도 분명하긴 한데, 장면 일관성이 떨어진다거나 퀄리티가 상업 일러스트 수준은 안 된다거나... 고급 기능이 필요하면 ComfyUI 써야지 별 수 있나. 가지고 놀 수준으로 그냥 적당한 듯.
