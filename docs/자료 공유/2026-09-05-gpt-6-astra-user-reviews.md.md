# GPT-6 Astra, 실사용자들은 어디에서 강하다고 느꼈나

GPT-6 Astra가 전면 배포되면서 실제 사용자들의 후기도 빠르게 쌓이고 있다.

출시 직후의 평가이므로 장기적인 결론을 내리기에는 이르다. 하지만 Reddit, 개발자 커뮤니티, Every의 실사용 테스트, CodeRabbit의 코드 리뷰 평가 등을 종합하면 반복해서 언급되는 강점은 꽤 분명하다.

결론부터 말하면 **Astra의 가장 큰 변화는 단순히 코드를 더 잘 작성하는 것이 아니라, 컴퓨터와 여러 도구를 직접 사용하면서 복잡한 작업을 끝까지 수행하는 능력**에 있다.

## 가장 평가가 좋은 것은 Computer Use

현재 가장 일관되게 좋은 평가를 받는 영역이다.

OpenAI의 공식 평가에서도 Astra는 다음과 같은 결과를 기록했다.

|벤치마크|GPT-6 Astra|GPT-5.6 Sol|
|---|--:|--:|
|OSWorld 2.0|72.6%|65.7%|
|ScreenSpot-Pro|92.7%|76.9%|

OSWorld는 실제 데스크톱 환경에서 프로그램을 조작하는 능력을 평가한다. ScreenSpot-Pro는 화면에서 필요한 위치를 찾아 조작하는 능력을 측정한다.

실사용 평가도 비슷하다. Every 팀은 Astra를 직접 사용해 소프트웨어 조작, 반복 업무, 콘텐츠 제작 등을 테스트한 뒤 computer use를 큰 개선점으로 평가했다.

즉 Astra에서는 다음과 같은 작업의 현실성이 크게 높아졌다.

```text
목표 전달
→ 프로그램 실행
→ 화면 확인
→ 필요한 조작
→ 결과 확인
→ 수정
```

기존에는 사람이 중간 과정을 상당 부분 관리해야 했다면, Astra에서는 이 루프 자체를 모델에게 맡길 수 있는 범위가 넓어졌다.

## 3D와 시각적 작업에서 특히 강하다

초기 Astra 후기에서 가장 눈에 띄는 분야 중 하나가 Blender와 3D 작업이다.

실사용자들은 건축물, 주택, 기계 등을 Blender 장면으로 만드는 테스트를 진행했고, 복잡한 결과물을 한 번의 요청으로 생성하는 사례들도 공개했다. 오래된 증기기관차 도면을 기반으로 Blender에서 3,295개의 개별 편집 가능한 오브젝트로 재구성한 사례도 있다.

Reddit에서도 Blender와 3D 게임 개발에서 이전 모델보다 좋은 결과를 얻었다는 초기 후기가 나오고 있다.

OpenAI 역시 Astra에서 웹사이트, 게임, 애플리케이션, 렌더링을 만들 때의 시각적 판단 능력이 강화됐다고 설명하고 있다.

따라서 Astra의 3D 능력은 단순히 Blender Python 코드를 잘 작성한다는 의미보다 범위가 넓다.

```text
장면 이해
→ 오브젝트 구성
→ 공간 관계 판단
→ Blender 조작
→ 결과 확인
→ 반복 수정
```

같은 작업 전체를 수행하는 능력이 개선된 것이다.

## 한 번에 완성도 높은 결과물을 만드는 데 강하다

Astra는 랜딩 페이지, 간단한 애플리케이션, 게임처럼 **요구사항이 다소 추상적인 작업을 통째로 맡겼을 때** 좋은 결과를 낸다는 평가도 많다.

Every의 테스트에서도 시각 디자인과 웹 애플리케이션 생성 능력이 높은 평가를 받았다. 특히 제품의 외형이나 인터랙션을 스스로 채워 넣는 성향이 강했다.

이 특징은 프로토타이핑이나 vibe coding에는 장점이다.

```text
"이런 앱 만들어줘"
```

라고 요청했을 때 개발자가 화면 구조, 컴포넌트, 세부 기능을 일일이 지정하지 않아도 꽤 많은 부분을 알아서 결정한다.

다만 이 특성에는 부작용도 있다.

## 필요 이상으로 만드는 성향도 있다

Every의 Kieran Klaassen은 Astra를 **"show horse, not a workhorse"**라고 평가했다. 시각적으로 흥미로운 결과와 빠른 프로토타이핑에는 강하지만, 일상적인 제품 개발에서는 Fable 계열 모델보다 신뢰하기 어렵다는 평가였다.

비슷한 문제는 다른 개발자 후기에서도 등장한다.

기존 아키텍처 안에서 작은 수정을 요구했는데 새로운 인프라나 구현 방식을 추가하거나, 사용자의 의도를 확인하기 전에 더 큰 변경을 시작했다는 사례가 보고됐다.

따라서 현재 초기 평가는 다음처럼 나눠볼 수 있다.

```text
"좋은 결과물을 알아서 만들어줘"
→ Astra에 유리

"기존 구조를 유지하면서 이것만 정확히 수정해줘"
→ 반드시 Astra가 더 낫다고 보기 어려움
```

Astra의 높은 자율성이 항상 장점인 것은 아니다.

## 대형 코드베이스에서는 강점이 보인다

코딩에서도 Astra가 좋은 평가를 받고 있지만, 단순한 코드 생성보다는 **여러 파일과 시스템 전체의 관계를 이해해야 하는 문제**에서 강점이 뚜렷하다.

CodeRabbit은 실제 코드 리뷰 평가에서 Astra의 actionable bug coverage를 측정했다.

전체 평가에서는 GPT-5.6 Sol보다 약 4% 높은 결과를 기록했지만, 여러 파일 사이의 관계를 이해해야 하는 어려운 cross-file 문제에서는 Sol보다 약 20% 높은 결과를 기록했다.

```text
전체 코드 리뷰
Astra 61.3%
Sol   59.0%

Cross-file 코드 리뷰
Astra 57.1%
Sol   47.6%
```

단순한 함수 구현보다 다음과 같은 작업에서 Astra의 장점이 커질 가능성을 보여준다.

- 대형 코드베이스 탐색
    
- 여러 파일에 걸친 버그 분석
    
- 기존 아키텍처 파악
    
- 복잡한 리팩터링
    
- 변경의 파급 효과 분석
    

즉 코딩 능력 역시 **더 많은 컨텍스트를 연결해서 판단하는 방향**으로 개선된 것으로 보인다.

## 속도도 좋은 평가를 받고 있다

Codex 사용자 후기에서는 Astra의 작업 속도가 빠르다는 반응도 반복되고 있다.

일부 사용자는 동일한 개발 작업에서 Sol보다 3~4배 정도 빠르게 느껴졌다고 평가했고, 여러 저장소에서 실제 작업을 시킨 뒤 속도를 가장 큰 개선점으로 꼽은 사례도 있다. 이는 개인 사용자의 체감이므로 일반적인 성능 차이로 단정할 수는 없다.

OpenAI는 API에 Astra Fast 모드도 제공하며, Standard 대비 최대 2배 빠르게 처리할 수 있다고 설명한다.

## 대신 사용량은 주의할 필요가 있다

속도가 빠르다고 해서 사용량까지 적은 것은 아니다.

Codex 사용자 사이에서는 Astra를 사용한 뒤 5시간 사용 한도가 빠르게 감소했다는 사례가 다수 보고되고 있다. Plus 사용자가 Astra Medium으로 단일 작업을 실행한 뒤 짧은 시간에 5시간 한도를 모두 사용했다는 사례도 있다.

반대로 Astra Light를 장시간 사용하면서 만족스러운 효율을 얻었다는 사용자도 있어 reasoning level과 작업 종류에 따른 차이가 큰 상태다.

따라서 아직은

```text
Astra = 항상 더 빠르고 저렴하다
```

라고 보기는 어렵다.

## 글쓰기와 일반 지식 작업도 개선됐다

Astra는 개발 전용 모델은 아니다.

Every의 실사용 테스트에서는 글쓰기, 소프트웨어 조작, 시각 디자인이 주요 강점으로 꼽혔다. Astra가 해당 리뷰 기사 자체의 초안을 한 번의 요청으로 작성했고, 편집자가 사람이 작성한 것으로 착각했다는 사례도 소개됐다.

출시 직후 일반 사용자 후기에서도 복잡한 비즈니스나 전문 업무 문제를 비교적 적은 추가 설명으로 처리하고, 답변이 간결하다는 평가가 나오고 있다. 다만 이는 아직 개인적인 초기 평가 수준이다.

## 결국 Astra의 핵심은 Agent 능력이다

GPT-5.6 Sol과 비교할 때 Astra의 특징을 단순히

```text
코딩을 더 잘한다
```

라고 설명하면 중요한 부분을 놓치게 된다.

현재까지의 실사용 평가를 종합하면 더 정확한 설명은 다음에 가깝다.

```text
GPT-5.6 Sol
→ 좋은 답과 코드를 생성하는 모델

GPT-6 Astra
→ 여러 도구를 사용하면서 복잡한 결과물을 직접 만들어가는 모델
```

특히 다음 영역에서 차이가 크게 나타나고 있다.

1. Computer Use
    
2. 장시간 Agent 작업
    
3. Blender와 3D 작업
    
4. UI와 시각 디자인
    
5. 대형 코드베이스 이해
    
6. 여러 단계가 필요한 전문 업무
    

반대로 작은 코드 수정이나 기존 설계를 정확히 따라야 하는 작업에서는 높은 자율성이 오히려 과잉 구현으로 이어질 수 있다는 지적도 존재한다.

따라서 출시 직후 기준으로 Astra는 **모든 작업에서 기존 모델을 단순히 대체하는 모델이라기보다, 사람이 프로그램과 도구를 직접 다루던 영역을 AI에게 넘길 수 있는 범위를 크게 넓힌 모델**이라고 보는 것이 현재 실사용 평가에 가장 가깝다.
