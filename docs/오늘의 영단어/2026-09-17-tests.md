# 2026-09-17 - tests

![tests 이미지](https://cdn.neuwappbox.com/docs/today-en-word/2026-09-17-tests-b35838df6019.webp)

* **발음**: /tests/
* **품사**: 명사, 동사
* **의미**:
  * 명사: 시험들, 검사들
  * 동사: test의 3인칭 단수형, 시험하다 또는 검사하다
* **형태**:
  * 기본형: test
  * 단수 명사: test
  * 복수 명사: tests
  * 3인칭 단수 동사: tests
  * 현재분사: testing
  * 과거형 및 과거분사: tested
* **예문**:
  * *The students have two science tests this week.*  
    학생들은 이번 주에 과학 시험이 두 개 있다.
  * *This button tests whether the alarm is working.*  
    이 버튼은 알람이 작동하는지 검사한다.
  * *Regular practice tests can make you feel more confident.*  
    정기적인 모의고사는 자신감을 더 높여 줄 수 있다.
* **유의어/관련어**: exam, quiz, assessment, check, trial
* **활용**:
  * **take a test**는 시험을 보다, **pass a test**는 시험에 통과하다라는 뜻입니다.
  * **test + 대상**은 무엇이 제대로 작동하는지 또는 어떤 성질이 있는지 검사할 때 씁니다. 예: *test the water*.
  * 명사 **tests**와 동사 **tests**는 철자가 같으므로 문장 속 위치로 뜻을 구별합니다. *The tests are hard*에서는 명사이고, *She tests the app*에서는 동사입니다.
* **어원**:
  * **test**는 라틴어 *testum*에서 왔습니다. 원래 금속을 가열하고 시험하던 그릇을 가리켰으며, 여기서 어떤 것의 성질이나 품질을 확인한다는 뜻이 생겼습니다.
* **트리비아**:
  * **test drive**는 자동차를 사기 전에 시험 운전하는 것을 말합니다. 비유적으로는 새 제품이나 방법을 잠시 써 보는 뜻으로도 쓰입니다.
  * 영어권 학교에서는 짧은 시험을 **quiz**, 더 큰 평가를 **test** 또는 **exam**이라고 부르는 경우가 많습니다.
